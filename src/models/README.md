# 🤖 Models Module

This directory will contain the Machine Learning models used to predict stock movements based on insider trading activity.

## 🧪 Planned Models
- **Baseline**: Simple logistic regression or Random Forest.
- **Advanced**: Gradient Boosting (XGBoost/LightGBM) or Time Series models.

## 📥 Input Data
Models will be trained on the processed dataset located in `data/processed/`.
